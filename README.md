# dudLis City: Snow Management

Минимальный playable-прототип браузерной игры про управление уборкой снега и коммунальными службами.

## Что уже реализовано

- Симуляция города из 8 районов.
- Динамическая погода (лёгкий снег, сильный снег, метель, мороз).
- Система накопления снега, пробок и удовлетворённости жителей.
- Управление ресурсами: бюджет, снегоуборочная техника, депо, реагенты.
- Журнал жалоб/событий.
- Упрощённый региональный рейтинг (ваш город + бот-города).

## Запуск

```bash
python3 -m http.server 4173
```

Откройте в браузере: `http://localhost:4173`

## Управление

- **Купить снегоуборщик** — повышает мощность уборки.
- **Расширить депо** — увеличивает логистическую эффективность и запас реагента.
- **Экстренное отопление** — быстрый буст удовлетворённости.
- **Обработка реагентом** — пополняет склад реагента.
- **Приоритет магистралей** — регулирует, насколько служба сфокусирована на главных дорогах.
- **Запустить метель** — тестовая кнопка для стресс-проверки города.

## Цель

Удерживать удовлетворённость выше 60% и не уходить в глубокий бюджетный дефицит во время затяжных снегопадов.
